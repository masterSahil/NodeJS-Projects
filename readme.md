# 🚀 Getting Started

Clone the repository:

```bash
git clone <repository-url>
```

Move into any project:

```bash
cd project-name
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```

or

```bash
npm start
```
